# Governance

## Principles

- Scientific integrity
- Transparent decision-making
- African institutional capability
- Public value
- Technical accountability
- Community relevance
- Reproducible evidence
- Non-partisan operation

## Decision classes

| Decision | Minimum review |
|---|---|
| Editorial documentation | One reviewer |
| Data transformation | Data reviewer |
| Scientific definition | Scientific and domain review |
| Mathematical model | Independent technical review |
| Country recommendation | Scientific, engineering and country-context review |
| Production release | Verification and validation approval |

## Independence

The project may collaborate with governments, institutions and leaders, but it is not a political party, campaign or personality-centered movement.
