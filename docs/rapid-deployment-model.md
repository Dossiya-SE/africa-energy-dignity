# Rapid Deployment Model

## Core sequence

`Evidence → Decision → Engineering → Finance → Procurement → Construction → Commissioning → Productive Impact`

## Time-to-impact indicator

`T_impact = T_diagnosis + T_design + T_approval + T_finance + T_procurement + T_construction + T_commissioning`

## Stage gates

| Gate | Decision |
|---|---|
| G0 | Mission and critical outcome |
| G1 | Baseline evidence sufficiency |
| G2 | Technical feasibility |
| G3 | Preferred scenario and tradeoffs |
| G4 | Delivery readiness |
| G5 | Execution performance |
| G6 | Commissioning compliance |
| G7 | Service and productive impact |
| G8 | Correction, reuse and scale |

## Rapid-execution principle

Reduce waiting, rework and fragmented decision-making. Do not remove verification, safety or critical quality controls.
